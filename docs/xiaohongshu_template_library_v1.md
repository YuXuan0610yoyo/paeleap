# 小红书模板库 V1.1


目标：让不懂运营的人，用少量选择得到完整推广笔记。


产品分类：古镇、自然风光、主题乐园。视觉建议：人文纪实、自然清新、活力体验。视觉建议不是已确认的研究分类。


## 古镇 / 人文纪实

让人看懂古镇有哪些具体看点，而不只觉得“很古风”。

用户输入：景点：乌镇西栅｜读者：首次来访｜重点：水乡、街巷、庭院

封面：乌镇西栅
先看这 3 种风景

标题：乌镇西栅｜水乡慢游，看这3处细节

图片顺序：
- 第1张：水乡主图，对应正文水乡看点
- 第2张：街巷实景，对应门窗与屋檐
- 第3张：庭院实景，对应树影与窗格
- 实用信息有资料才加入正文，不额外凑图

画面：保留真实木屋、水面与街巷；米白、木色作辅助。大标题不遮建筑，每页只解释一个看点。水墨可选，不能作为古镇的强制风格。

正文：一个具体到访理由 → 2–3个亮点，每点一句“看什么” → 适合谁 → 一句自然提问。没有路线资料时，只写看点清单，不写游览先后。

依据：P1, P4, P7, P8

## 自然风光 / 自然清新

让人判断风景是否适合自己，以及该怎样安排欣赏。

用户输入：景点：杭州西湖｜读者：喜欢散步的人｜重点：湖面风景

封面：杭州西湖
慢下来，看湖面风景

标题：杭州西湖｜把目光留给湖面与岸线

图片顺序：
- 封面：最符合主题的一张景色
- 第2张：地点总览或看点清单
- 第3–4张：逐个看点的实景
- 末页：有资料才加步行、天气提醒

画面：主体清楚，蓝绿与自然光保持一致；留出画面呼吸空间。若主打路线，第二页用真实地图和已核实站点；没有路线资料时改为看点卡。

正文：适合什么心情或人群 → 具体景色 → 怎样欣赏 → 实用提醒。季节、花期、天气和路程只用确认过的信息。

依据：P2, P3, P4, P6, P12

## 主题乐园 / 活力体验

让人先知道有什么可玩，再判断哪些项目适合同行的人。

用户输入：景点：千岛湖山野乐园｜读者：亲子／朋友｜重点：滑车体验

封面：[乐园名]
先选适合你的玩法

标题：千岛湖山野乐园｜滑车怎么玩？先看体验画面

图片顺序：
- 封面：一个真实项目的动作画面
- 第2张：按同行人群挑项目
- 第3–4张：每页一个项目/动作
- 末页：身高、预约、场次等有效提示

画面：用动作与人物说明体验，明亮强调色只作点缀；项目编号和短标签统一。不要把项目堆满一张图，也不把历史截图当成当前活动介绍。

正文：同行人群的需求 → 项目清单（玩什么/适合谁） → 安排提醒 → 询问偏好的玩法。未确认身高限制、场次和开放状态时，不填具体数字。

依据：P5, P13, P15, P17, P18, P19, P20
